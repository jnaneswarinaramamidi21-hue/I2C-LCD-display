# Arduino I2C LCD Display

This project demonstrates interfacing a 16x2 I2C LCD display with Arduino UNO using the I2C communication protocol.

The LCD is used to display text and messages through only two communication wires (SDA and SCL).

## Components Used
- Arduino UNO
- 16x2 I2C LCD Display
- Breadboard
- Jumper Wires

## Files
- sketch.ino → Arduino source code
- diagram.json → Circuit connections
- wokwi-project.txt → Wokwi project details

## Concepts Learned
- I2C Communication
- LCD Display Interfacing
- SDA and SCL Pins
- Arduino Output Display
